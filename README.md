# Программное Обеспечение для автоматической регистрации аккаунтов яндекса.

Функционал:
  - Возможность использования прокси;
  - Интеграция с API Spanch SMS;
  - Возмоность ввода уже готовых номеров;
  - Автоматическая генерация ФИ, логина, пароля и запись в файл.

---

# Запуск 🚀
Для начала скачиваем репозиторий на свое устройство при помощи GIT или архивом.

Устанавливаем все зависимости:
> cd {место где лежит проект}

> pip install -r requirements.txt

Запускаем программу:
> python main.py `(для Windows)`

> python3 main.py `(для MacOS)`

---

# Настройка ⚙️
## Заполните следующие файлы в соответствии с инструкцией, вложенной в них:
### config.py:
`Содержит важные переменные, такие как API-ключ SMS, настройка таймаутов и т.п.`

### numbers.txt:
`Содержт "кастомные" / "ручные" номера, заполните файл если не планируете использовать API`

### proxys.txt:
`Содержит прокси, заполните файл, если планируете использовать прокси (рекомендуется)`
